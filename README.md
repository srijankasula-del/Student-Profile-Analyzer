# 🎓 Student Profile Analyzer

An interactive student performance dashboard built using modern HTML, CSS and JavaScript.

## 🚀 Features
- Add & Delete Students
- Update Scores
- Search Functionality
- Sorting Options
- Real-time Class Statistics
- Local Storage Persistence

## 🛠 Tech Stack
- HTML5
- CSS3 (Modern UI Design)
- JavaScript (OOP + DOM Manipulation)
